# Incident — release 1.1.0 rejetée

| | |
|---|---|
| Date | 5 novembre 2026 |
| Version concernée | CargoFlow 1.1.0 (branche `release/1.1.0`, non fusionnée) |
| Impact client | **aucun** : la version n'a jamais reçu de trafic de production |
| Détection | tests de contrat (CI) puis smoke test avant bascule |

## Résumé

La 1.1.0 annonçait une mise à jour du calcul des devis « avec le même barème ». En réalité,
au-delà de 100 km le tarif kilométrique passe de 0,40 € à 0,04 € :

```js
const distanceRate = distanceKm > 100 ? 4 : 40;
```

Pour 120 km et 3 kg, l'API répond **10,40 €** au lieu de **53,60 €**. Les quatre tests fournis
avec la version passent tous : ils ne testent qu'un devis à 20 km.

## Chronologie

1. Intégration de l'archive sur la branche `release/1.1.0` (src/ et package.json repris tels quels).
2. `npm test` / job `unit_tests` : **4 tests de contrat en échec** (101, 120, 500 et 2000 km).
   Le pipeline s'arrête : pas d'image, pas de déploiement.
3. Vérification de la deuxième barrière : image 1.1.0 construite à la main (hors pipeline) et
   déployée en production avec `scripts/deploy.sh production 1.1.0`.
   - la couleur green démarre et devient prête ;
   - le smoke test via la préversion échoue : `devis 120 km / 3 kg = 53.60 EUR : montant obtenu '10.4'` ;
   - **release rejetée, aucune bascule**, green arrêtée, le trafic reste sur 1.0.0 (blue).
4. Historique : `production | deploy | 1.1.0 | green | REJETÉE`.

## Décision

- La 1.1.0 n'est pas livrée. Le défaut est signalé à l'équipe qui fournit le code métier.
- Le code métier n'est pas corrigé par nous (consigne du projet).

## Enseignements

- Les tests livrés avec une version ne suffisent pas : nos **tests de contrat** (barème sur
  plusieurs distances, dont >100 km) sont la première barrière.
- Le **smoke test avant bascule** couvre aussi le cas où une image défectueuse arriverait
  jusqu'au déploiement : il vérifie trois distances dont une au-delà de 100 km.

## Reproduire

```bash
git switch release/1.1.0 && npm test          # 4 échecs attendus
git switch main
scripts/build.sh release/1.1.0                # refuse de construire (tests en échec)

# Forcer l'image pour tester la barrière de déploiement :
D=$(mktemp -d); git archive release/1.1.0 | tar -x -C "$D"
docker build --build-arg APP_VERSION=1.1.0 -t cargoflow-api:1.1.0 "$D"; rm -rf "$D"
scripts/deploy.sh production 1.1.0            # RELEASE REJETÉE, trafic inchangé
```
