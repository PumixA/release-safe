# CargoFlow API 1.1.0

## Calcul des devis

Cette livraison met à jour le calcul des devis.

- Les routes et les paramètres restent inchangés.
- Le format des réponses est conservé.

Le barème attendu reste le même :

- 5 € fixes.
- 0,40 € par kilomètre.
- 0,20 € par kilogramme.

## Version

`/api/version` renvoie `1.1.0` par défaut.

Si votre déploiement définit `APP_VERSION`, mettez cette valeur à jour pour identifier la version livrée.
